# GitHub Pages deployment

The site lives in the `docs/` folder of this repository (`assets/`, `screenshots/`, `index.html`, `privacy.html`, `support.html`, `404.html`, `styles.css`, `robots.txt`, `sitemap.xml`).

In GitHub, open **Settings > Pages**, choose **Deploy from a branch**, then select `main` and `/docs`. Pushing changes under `docs/` to `main` republishes the site.

Published URLs:

- Home: `https://vitaliesdev.github.io/rutracker-visual-enhancer/`
- Privacy: `https://vitaliesdev.github.io/rutracker-visual-enhancer/privacy.html`
- Support: `https://vitaliesdev.github.io/rutracker-visual-enhancer/support.html`
