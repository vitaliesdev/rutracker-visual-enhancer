# Store screenshot guide

Chrome Web Store requires at least one and allows up to five screenshots. Use **1280x800** for every screenshot. Capture the exact final ZIP installed in Chrome; do not use design mockups as product screenshots.

## Browser preparation

1. Use a clean Chrome window at 1280x800 CSS pixels and 100% zoom.
2. Disable other dark-mode extensions so only RuTracker Visual Enhancer controls the page theme.
3. Use the final 1.1.0 Store package.
4. Hide bookmarks, personal usernames, notifications, and unrelated tabs.
5. Use neutral tracker results that do not show sensitive imagery or personally identifying information.

## Recommended set

### 01 — Main visual result view

- Dark theme, M poster size.
- Toolbar, posters, Topic, Download, Author, Size, Seeds, Leeches, Download count, and Added visible.
- 3–4 complete rows.
- Suggested filename: `01-visual-results-dark-1280x800.png`.

### 02 — Light theme and filtering

- Light theme.
- Enter a short neutral query in Filter results.
- Keep the result counter visible.
- Suggested filename: `02-fast-filter-light-1280x800.png`.

### 03 — Infinite scrolling

- Show a page divider such as “Results 51–100 · Page 2”.
- Keep the Infinite scroll switch visible and enabled.
- Suggested filename: `03-infinite-scroll-1280x800.png`.

### 04 — Custom columns and poster sizes

- Open the Columns menu.
- Show S/M/L controls in the same frame.
- Suggested filename: `04-customize-view-1280x800.png`.

### 05 — Language popup

- Open the pinned extension popup with the language selector visible.
- Use a neutral tracker background.
- Suggested filename: `05-language-options-1280x800.png`.

## Quality rules

- No padding around the screenshot; use the full 1280x800 canvas.
- Do not stretch or upscale a smaller screenshot.
- Avoid excessive text overlays. The product UI should explain itself.
- Use square corners.
- Verify every screenshot reflects version 1.1.0 exactly.
